AI Tools Quick Launcher & Research Organizer

── AI Tools Quick Launcher ──

Pin shortcuts to your favourite AI assistants — ChatGPT, Gemini, Copilot, Claude, Grok, Perplexity, Deepseek, and more. Switch between a compact grid view and a full list view. Click any tile to open the tool; if it's already open in another tab, the extension switches to that tab instead of opening a duplicate.

Add any AI tool not in the built-in list by providing a name and URL. Reorder tools with one click. Edit names, URLs, and icons (fetch favicon automatically, upload a custom image, or reuse an existing one).

── Project Resource Organiser ──

Group AI chat sessions, Google Drive documents, and general web links under named projects. Each project contains three structured subfolders:

  • 🤖 AI Sessions — links to AI conversations
  • △ Google Drive — Docs, Sheets, Slides, and Drive files
  • ☑ Resources — articles, tutorials, and references

Create topic folders inside any subfolder to organise further. Save links from the active browser tab with a single click. The extension auto-detects the link type and suggests the right subfolder.

── Bookmark Sync ──

Mirror your entire project tree into a Chrome Bookmarks folder with one click. Use it as a backup or access your projects from any synced device.

── Recycle Bin ──

Accidentally deleted something? The Recycle Bin holds removed items so you can restore them before they are permanently gone.

── Key Features ──

  • Lives in Chrome's built-in side panel — no separate window or tab needed
  • Grid and list layout for AI tools, saved per session
  • 12 predefined AI tools + unlimited custom tools
  • Drag-free reordering with ▲ ▼ controls
  • Favicon fetch, image upload, or icon reuse for tool icons
  • Hierarchical project structure (Projects → Subfolders → Topics → Links)
  • One-click bookmark sync for backup and cross-device access
  • Recycle bin with restore support
  • All data stored locally using Chrome storage — no account required
  • No external servers, no data collection

── Permissions Used ──

  • Side Panel — to display the manager panel
  • Storage — to save your tools, projects, and preferences locally
  • Tabs — to detect the active tab URL when saving links and to reuse open tabs
  • Bookmarks — to sync your project tree to Chrome Bookmarks
